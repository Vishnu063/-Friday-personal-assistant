# Security reports

For a vulnerability, use the repository's private vulnerability reporting feature if enabled. Do not publish credentials, private screenshots or exploit data containing personal information. If private reporting is unavailable, open a minimal issue requesting a private reporting channel without sensitive details.

Security boundaries: explicit Android permission grants, fresh device authentication for sensitive phone requests, no AI execution tools, no background screen-text collection and no direct network permission. This is an early personal preview, not a security-certified product.
